站点搭好了，这是第一篇文章。

## 接下来可以做的事

1. 打开 [PagesCMS](https://app.pagescms.org/)，用 GitHub 账号登录
2. 选中这个仓库，就能看到「文章」「独立页面」「站点设置」三个入口
3. 改完点 Save，它会自动提交一个 commit 到 `main`
4. GitHub Actions 跑完，网站就更新了

全程不用碰命令行，也不用本地装 Hugo。

## 写作提示

- 正文用 Markdown，`##` 会自动进目录
- 想让文章不公开，把 `draft` 勾上
- 封面图可以在编辑界面直接上传，会存到 `static/images/`
